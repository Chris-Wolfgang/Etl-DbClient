Remarks

Supplied ahead of the optional transaction and logger. When the whole options object is null, or an individual property is left unset, the documented defaults below apply — defaults live on the property initializers here rather than in constructor bodies, so no constructor can accidentally diverge from them.

The record is not generic: none of these settings depends on the record type being extracted.

This record deliberately exposes no Parameters property. Dapper's DynamicParameters is a third-party type, and keeping it off the public surface is what allows the ORM to be swapped later without a breaking change for consumers. Supply parameters through the constructor overload that takes an IDictionary<string, object>.

PagingClauseTemplate

Gets the dialect-specific paging clause appended when server paging is active. Defaults to None — no dialect chosen.

public string? PagingClauseTemplate { get; init; }

Property Value

string

Remarks

This is dialect-specific, not standard SQL. The default is the PostgreSQL / MySQL / SQLite form; SQL Server rejects LIMIT and needs the SQL:2008 OFFSET … ROWS FETCH NEXT … ROWS ONLY form, as do Oracle 12c+ and Db2. Leaving the default in place against those engines produces a runtime syntax error.

Use PagingClauseTemplates rather than writing the clause by hand: PagingClauseTemplate = PagingClauseTemplates.SqlServer. Any string is accepted, so a dialect with no preset can be supplied directly.

The OFFSET … FETCH form additionally requires an ORDER BY at the end of the command text you supply — the paging clause is appended after it, so the finished statement ends with the paging clause, not the ORDER BY. SQL Server and Oracle both reject the form otherwise.

A custom template must reference both @PageOffset and @PageLimit — those are the parameter names supplied when ServerOffset and ServerLimit are set.

Remarks

The property itself stays null unless set; when paging is active an unset offset is treated as 0. Paging is switched on by ServerLimit, so an offset with no limit throws — no page size can be inferred.
