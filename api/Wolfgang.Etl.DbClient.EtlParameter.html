Remarks

Supply instances as values in the IDictionary<string, object> passed to a DbExtractor<TRecord> or DbLoader<TRecord> constructor. A dictionary entry whose value is not an EtlParameter (and not a DbParameter) is treated as a plain input value, exactly as before.

This type exists so that direction, DbType and size can be expressed without exposing a third-party parameter type on this package's public surface — which is what keeps the underlying data-access library replaceable.

Use the generic EtlParameter<T>; this base carries only what parameter binding needs to read without knowing the value's type.

Remarks

Not every provider supports every direction, and the check happens when this parameter is mapped onto a provider parameter — that is, when extraction or loading runs, not when this object is constructed. Microsoft.Data.Sqlite, for example, rejects Output outright.
