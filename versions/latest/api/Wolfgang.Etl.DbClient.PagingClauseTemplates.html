Remarks

Server-side paging syntax is dialect-specific, not standard SQL. LIMIT … OFFSET … is the PostgreSQL / MySQL / SQLite form; SQL Server rejects LIMIT outright and wants the SQL:2008 OFFSET … ROWS FETCH NEXT … ROWS ONLY form, as do Oracle 12c+ and Db2.

These are conveniences, not a closed set — PagingClauseTemplate takes any string, so a dialect with no preset here is supplied directly.

Every template must reference both @PageOffset and @PageLimit: those are the parameter names the extractor supplies when ServerOffset and ServerLimit are set.

Remarks

This does NOT disable paging — paging is switched on by ServerLimit, with ServerOffset defaulting to 0. None means the dialect has not been named yet, so activating paging while it is in effect is an error rather than a silent guess: there is no portable paging syntax, and any default this library picked would be wrong on half the engines it supports.
