Remarks

Connection lifetime follows the existing ManageConnection and ManageConnection semantics — the pipeline does not override ownership. When ManageConnection is true the extractor / loader opens and closes the connection; otherwise the caller owns it. There is no DisposingOwned-style resource handoff, because unlike file loaders there is no file handle created by the factory itself.

Dry-run behaviour on the loader flows through the shared Wolfgang.Etl.Abstractions.ISupportDryRun pipeline hook rather than a DbClient-specific setter, consistent with the other loaders.
