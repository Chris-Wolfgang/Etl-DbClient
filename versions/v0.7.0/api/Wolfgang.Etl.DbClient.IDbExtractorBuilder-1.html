Fluent builder for a DbExtractor<TRecord> hung off the generic Wolfgang.Etl.Abstractions.EtlPipeline chain. Extends Wolfgang.Etl.Abstractions.IEtlPipeline<T>, so a consumer transitions from configuring the extractor to appending pipeline operators simply by calling one — no explicit Build() step.

Remarks

Each setter maps 1:1 to a public property on DbExtractor<TRecord>; no new configuration surface is introduced. Setters return the builder for chaining and take effect on the next enumeration of the pipeline.
