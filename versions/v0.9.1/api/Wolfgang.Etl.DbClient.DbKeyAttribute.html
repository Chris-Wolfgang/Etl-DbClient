Marks a property on a DbTableAttribute-decorated record as part of the row's identifying key. The DbTableGenerator source generator uses [DbKey] properties to build the WHERE clause of the generated Update and Delete SQL constants.

Remarks

A type may carry more than one [DbKey] property to model a composite key. Column ordering in the emitted WHERE clause matches the property declaration order.

[DbKey] is orthogonal to DbColumnAttribute: a key property may also carry a [DbColumn] override for the SQL column name, and the aliasing rule matches the runtime DbCommandBuilder emitter.

[PublicAPI] marks the attribute as consumed by downstream NuGet consumers + the DbTableGenerator source generator — ReSharper has no visibility into those external / generated readers.
