Fluent builder for a DbLoader<TRecord> that terminates a generic Wolfgang.Etl.Abstractions.EtlPipeline chain. Extends Wolfgang.Etl.Abstractions.IEtlPipelineSink, so a consumer transitions from configuring the loader to running the pipeline simply by calling RunAsync(IProgress<EtlPipelineProgress>, CancellationToken) — no explicit Build() step.

public interface IDbLoaderBuilder<T> : IEtlPipelineSink where T : notnull

Remarks

Each setter maps 1:1 to a public property on DbLoader<TRecord>; no new configuration surface is introduced. Setters return the builder for chaining and take effect on RunAsync(IProgress<EtlPipelineProgress>, CancellationToken).
